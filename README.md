
⚙️ Inicializar Condiciones Base

Cuando levantas el sistema por primera vez, es necesario crear un registro de condición base para cada estudiante.
Esto evita errores al momento de consultar o editar en el frontend.

🚀 Ejecución

Ejecuta el siguiente comando:

pnpm init-condicion-base

📋 ¿Qué hace este script?

🔍 Revisa todos los estudiantes en la base EstudiantesDonBoscoSucre.

🗂️ Verifica si ya tienen un documento de condición base en clinicodb.

🟢 Crea una condición base vacía si no existe.

🖥️ Ejemplo de salida
🟢 Creada condición base para estudiante JUAN
🟢 Creada condición base para estudiante CARLOS
✅ Estudiante PEDRO ya tenía condición base

Resumen: 15 creados, 1 ya existían
